🚀 Getting Started ▶

Launch the Hermes desktop app with:

hermes desktop    # or:  hermes gui

The desktop app is a native Electron application for macOS, Windows, and Linux. It gives you a polished chat interface with streaming tool output, side-by-side previews, a file browser, voice mode, cron schedules, profile management, skills browser, and full settings.

🪟 Key UI Features ▶
  • Streaming chat — see tool calls and responses live
  • Side-by-side preview — preview HTML, markdown, images alongside chat
  • Cmd+K palette — quick access to every command and setting
  • Drag-and-drop files — drop images, PDFs, code into chat
  • File browser — navigate project files without leaving the app
  • Session list — browse, resume, rename, delete sessions
  • Voice mode — speak to Hermes and hear responses
  • Cron tab — manage scheduled tasks visually
  • Skills & memory browser — see what Hermes has learned
  • Profile switcher — switch between profiles on the fly
  • Notifications — native OS notifications for important events
🔌 Desktop Plugins ▶

Extend the desktop app with UI plugins that add custom panes, commands, and widgets. Plugins live in ~/.hermes/desktop-plugins/.

You can add: Panes (custom side panels), Commands (new Cmd+K actions), Widgets (inline UI components in the chat area).

🎨 Skins & Themes ▶

Change how Hermes looks across CLI, TUI, desktop, and dashboard.

hermes skin list                       # list available skins
hermes config set display.skin synthwave   # apply live
hermes skin set accent "#ff6496"           # tweak one color

Tip: Don't fork the default skin — it drops the palette. Edit the active skin instead.

🐾 Pet Mascots (Petdex) ▶

Adopt an animated mascot that reacts to Hermes's activity across the CLI, TUI, and desktop app.

hermes pets list             # see available pets
hermes pet select <slug>    # activate one

Or hatch your own with /hatch [description].

👤 Profiles ▶

Run multiple independent Hermes instances with separate configs, sessions, skills, and memory.

hermes profile list                # list profiles
hermes profile create work --clone preston   # clone from existing
hermes profile use work            # switch to it
hermes --profile work              # use for one command
hermes profile export work         # share a profile

Each profile: ~/.hermes/profiles/<name>/.

🧠 What Are Skills? ▶

Skills are Hermes' procedural memory — reusable step-by-step instructions for how to do things. When Hermes encounters a familiar task, the matching skill loads automatically.

vs Memory: Memory stores facts (who you are, preferences, project details). Skills store procedures (how to do something). Both persist across sessions.

~90 skills bundled, ~60 optional installable ones.

📚 Managing Skills ▶
hermes skills list                # see installed
hermes skills browse               # interactive browser
hermes skills search "deployment"  # search descriptions
hermes skills install <id>        # install from hub or URL
hermes skills config               # enable/disable per platform
hermes skills check                # validate
hermes skills update               # update from source
hermes skills uninstall <name>    # remove

In-session: /skills, /learn <source>, /curator.

📝 How to Write a Skill ▶

Skills are markdown with YAML frontmatter:

---
name: my-skill
description: "Use when deploying to Fly.io."
version: 1.0.0
---

# My Skill
1. First do this
2. Then do that

Or use /learn ~/my-project to create one from a directory.

❓ Common Questions ▶

Quick answers to the most frequent questions about Hermes.

❓ Which model should I use? ▶
  • Best overall: Claude Opus 4 / GPT-5 via OpenRouter or Nous Portal
  • Fast & cheap: Claude Sonnet / GPT-4o mini / Gemini Flash
  • Coding: Claude Opus 4 / GPT-5-codex / DeepSeek Coder
  • Local (free): Qwen 3.5, Llama 3.x via Ollama
  • Newcomer: Nous Portal — one OAuth login, 300+ models

Run hermes model to pick interactively.

❓ How much does it cost? ▶
Hermes is free and open-source (MIT). You only pay for LLM API usage. Local models are completely free.
❓ Is my data sent anywhere? ▶
API calls go only to the LLM provider you configure. Hermes does not collect telemetry, usage data, or analytics. Everything is stored locally in ~/.hermes/.
❓ Can I use it offline? ▶
Yes! Use local models via Ollama, llama.cpp, vLLM. Run hermes model and select Custom endpoint → http://localhost:11434/v1.
❓ What's the difference between memory and skills? ▶
Memory = facts about you and projects. Skills = procedures for how to do things. Both persist across sessions.
❓ Can multiple people use one instance? ▶
Yes — via the messaging gateway (Telegram, Discord, Slack, WhatsApp). Access is controlled through allowlists and DM pairing.
❓ How do I update Hermes? ▶
hermes update or /update in-session. After updating, restart any running gateway processes.

🩹 First Aid Checklist ▶
hermes doctor --fix          # Check and fix deps/config
hermes auth status           # Check API keys/OAuth
hermes logs -f errors        # Look at error logs
hermes status --full         # See component health

Gateway issues: grep -i "failed to send\|error" ~/.hermes/logs/gateway.log | tail -20

💥 "hermes: command not found" ▶
Fix: 
source ~/.bashrc    # bash
source ~/.zshrc     # zsh
Verify: which hermes, ls ~/.local/bin/hermes.
🔇 Tool not available ▶
  1. hermes tools — check toolset enabled for your platform
  2. Some tools need env vars — check ~/.hermes/.env
  3. /reset after enabling (new session needed)
🔑 Model/Provider Issues ▶
  1. hermes doctor — check deps and config
  2. hermes auth — re-authenticate OAuth providers
  3. Check ~/.hermes/.env has the right API key
  4. Copilot 403: gh auth login tokens do NOT work for Copilot API. Use the Copilot-specific OAuth flow via hermes model → GitHub Copilot
🔄 Changes Not Taking Effect ▶
  • Tools/skills: /reset starts a new session
  • Config (gateway): /restart
  • Config (CLI): Exit and relaunch Hermes
🌐 web_extract Shows Stale Page ▶

Results cached for 20 minutes. Bypass with exempt hosts, min TTL, or disabling cache entirely:

# config.yaml — choose one:
web:
  cache_exempt_hosts:
    - mysite.vercel.app
    - "*.ngrok-free.app"

# Or: web.cache_ttl_minutes: 1   (min TTL)
# Or: web.cache_enabled: false   (disable entirely)

Localhost/private IPs are always fetched live.

🎙 Voice Not Working ▶
  1. Check stt.enabled: true in config
  2. Install whisper: python -c "import pm; pm.sync_venv(['stt-whisper'], explicit=True)"
  3. In gateway: /restart. In CLI: exit and relaunch.
⚙️ Gateway Dies on SSH Logout ▶
  • SSH logout: sudo loginctl enable-linger $USER
  • WSL2: systemd=true in /etc/wsl.conf
  • Crash loop: systemctl --user reset-failed hermes-gateway
🔧 Discord / Slack Bot Issues ▶
  • Discord silent: Enable Message Content Intent in Bot settings
  • Slack only DMs: Subscribe to message.channels event
